Commands

Everything lives under /rezero. You need to be an operator for almost all of it. The few that anyone can use are marked.

Some of these work on mobs too. Anywhere the target is an entity rather than a player, you can pass a UUID, and tab-completion will offer whatever you happen to be looking at. That covers authority, protection and magic.

Quick ones

/rezero checkpoint          save the world right now
/rezero halfheart           drop yourself to half a heart (anyone can use this)
/rezero revive <player>     bring a player back

Authorities

/rezero authority <entity> returnbydeath acquired <true|false>
/rezero authority <entity> domain        acquired <true|false>

/rezero authority <entity> sloth acquired      <true|false>
/rezero authority <entity> sloth witchfactor   <true|false>
/rezero authority <entity> sloth variant       <invisibleprovidence|unseenhands|sekhmet>
/rezero authority <entity> sloth compatibility <get|set <amount>>

/rezero authority <entity> greed acquired      <true|false>
/rezero authority <entity> greed witchfactor   <true|false>
/rezero authority <entity> greed variant       <lionsheart|corleonis|echidna>
/rezero authority <entity> greed compatibility <get|set <amount>>
Giving one out might take it from someone else. Only if your server switched on the single holder setting, which is off by default.

Gate

/rezero gate <player> get
/rezero gate <player> set <open|partly_open|damaged|destroyed|defective>
/rezero gate <player> defective get
/rezero gate <player> defective set <no_absorption|no_release>
/rezero gate <player> output     <get | set <amount>>
/rezero gate <player> efficiency <get | set <amount>>
/rezero gate <player> strain     <get | set <0-100>>
What you set is what you get. Blessings set someone's Gate when they receive them, but they don't keep holding it there. A Gate you set by hand stays that way.

Magic

/rezero magic <entity> <fire|water|earth|wind|yin|yang> acquired <true|false>
/rezero magic <entity> reroll

Divine Protections

/rezero protection <entity> get
/rezero protection <entity> reroll
/rezero protection <entity> add    <blessing>
/rezero protection <entity> remove <blessing>
/rezero protection <entity> remove all

Both add and remove tab-complete. Add offers every blessing in the game, remove only offers the ones that target actually has.

Stats

/rezero stats <player> <stat> get
/rezero stats <player> <stat> max                       push the level to its ceiling
/rezero stats <player> <stat> set <amount|max>
/rezero stats <player> <stat> proficiency <get | set <amount|max>>
/rezero stats <player> <stat> capacity    <get | set <amount|max>>

Stats are tenacity, fortitude, strength, reflexes, magic and combat.

Spirits

/rezero spirit <player> get
/rezero spirit <player> add    <element> <lesser|quasi|normal|great>
/rezero spirit <player> add    named <puck|beatrice>
/rezero spirit <player> remove <element> <rank>
/rezero spirit <player> remove named <puck|beatrice>
/rezero spirit <player> remove all
/rezero spirit <player> affinity <get | set <value>>
/rezero spirit <player> recall
/rezero spirit <player> unanchor <all | <name>>

recall is the fix when someone's spirit has gone quiet because it's stuck in an unloaded chunk.

Character

/rezero race     <player> <get | set <human|elf|half_elf>>
/rezero age      <player> <get | set <amount>>
/rezero lifespan <player> <get | set <amount>>
/rezero mana     <player> <get | set <amount>>
/rezero od       <player> <get | set <amount>>

Remember that lifespan is where mana and Od come from, so changing race quietly changes both.

Presets and wiping someone

/rezero data <player> preset <subaru|reinhard>
/rezero data <player> reset
A preset wipes everything first. It clears the target's magic, stats, authorities, spirits and blessings before applying anything, so they end up with exactly the preset and nothing else.

Turning off costs

/rezero skill cooldown <player> <true|false>   ability cooldowns on or off
/rezero skill cooldown <player> reset         clear every current cooldown
/rezero skill manacost <player> <true|false>  mana costs on or off

Useful for testing, or for building something without burning your Od.

Allies

These are for players and need no operator permission.

/rezero ally request <player>
/rezero ally accept  <player>
/rezero ally decline <player>
/rezero ally remove  <player>
/rezero ally attacks <get | <true|false>>     let allies damage you or not

World

/rezero chunkmana    <get | set <amount>>      ambient mana in this chunk
/rezero chunkmiasma  <get | set <amount>>      miasma in this chunk
/rezero sagecandidate <player> <true|false>

The chunk commands are handy for checking whether a spot has actually run dry, which is a common complaint from casters who've been sitting in one place.
