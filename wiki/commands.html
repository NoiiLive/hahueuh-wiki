Commands

The /rezero command tree \x{2014} for admins, testing, and roleplay setup.

All of these require permission level 2 (operator). Most take a player argument; the entity forms accept any living entity, and will suggest whatever you are looking at.

Gate

/rezero gate <player> get
/rezero gate <player> set <open|partly_open|damaged|destroyed|defective>
/rezero gate <player> defective get
/rezero gate <player> defective set <no_absorption|no_release>
/rezero gate <player> output   <get|set <amount>>
/rezero gate <player> efficiency <get|set <amount>>
/rezero gate <player> strain   <get|set <0-100>>
What you set is what you get. Divine Protections stamp the Gate when you receive them, but they do not hold it there. A gate you set by command stays set.

Character

/rezero race     <player> <get|set <human|elf|half_elf>>
/rezero age      <player> <get|set <amount>>
/rezero spirit   <player> ...
/rezero data     <player> preset <name>
/rezero data     <player> reset
preset wipes first. Applying a preset clears the target's magic, stats, authorities, spirits and protections before it writes anything, so the preset is all they are left holding.

Spirits

/rezero spirit <player> get
/rezero spirit <player> add    <school> <rank>
/rezero spirit <player> add    named <puck|beatrice>
/rezero spirit <player> remove <school> <rank>
/rezero spirit <player> remove all
/rezero spirit <player> affinity <get|set <value>>
/rezero spirit <player> recall
/rezero spirit <player> unanchor <all|<name>>
