Commands

Everything lives under /rezero. Most branches need permission level 2; the few that do not are marked.

Some commands take any entity, not just players. Where the argument is an entity — authority, protection, magic — you can pass a UUID, and the tab-completion will suggest whatever you are currently looking at.

Quick actions

/rezero checkpoint          take a Return by Death checkpoint immediately
/rezero halfheart           set yourself to half a heart  (no permission needed)
/rezero revive <player>     revive a player

Authorities

/rezero authority <entity> returnbydeath acquired <true|false>
/rezero authority <entity> domain        acquired <true|false>

/rezero authority <entity> sloth acquired      <true|false>
/rezero authority <entity> sloth witchfactor   <true|false>
/rezero authority <entity> sloth variant       <invisibleprovidence|unseenhands|sekhmet>
/rezero authority <entity> sloth compatibility <get|set <amount>>

/rezero authority <entity> greed acquired      <true|false>
/rezero authority <entity> greed witchfactor   <true|false>
/rezero authority <entity> greed variant       <lionsheart|corleonis|echidna>
/rezero authority <entity> greed compatibility <get|set <amount>>
Granting may revoke someone else. While singleAuthorityHolder is on — the default — giving an Authority to a new holder takes it from the previous one.

Gate

/rezero gate <player> get
/rezero gate <player> set <open|partly_open|damaged|destroyed|defective>
/rezero gate <player> defective get
/rezero gate <player> defective set <no_absorption|no_release>
/rezero gate <player> output     <get | set <amount>>
/rezero gate <player> efficiency <get | set <amount>>
/rezero gate <player> strain     <get | set <0-100>>
What you set is what you get. Divine Protections stamp the Gate when you receive them, but they do not hold it there. A Gate you set by command stays set.

Magic

/rezero magic <entity> <fire|water|earth|wind|yin|yang> acquired <true|false>
/rezero magic <entity> reroll

Divine Protections

/rezero protection <entity> get
/rezero protection <entity> reroll
/rezero protection <entity> add    <protection>
/rezero protection <entity> remove <protection>
/rezero protection <entity> remove all

Both add and remove tab-complete — add from every registered protection, remove from only the ones that entity actually holds.

Stats

/rezero stats <player> <stat> get
/rezero stats <player> <stat> max                      raise the level to its cap
/rezero stats <player> <stat> set <amount|max>
/rezero stats <player> <stat> proficiency <get | set <amount|max>>
/rezero stats <player> <stat> capacity    <get | set <amount|max>>

<stat> is one of tenacity, fortitude, strength, reflexes, magic, combat.

Presets and wiping

/rezero data <player> preset <subaru|reinhard>
/rezero data <player> reset
A preset wipes first. Applying one clears the target's magic, stats, authorities, spirits and protections before it writes anything, so the preset is all they are left holding.

Skill toggles

/rezero skill cooldown <player> <true|false>   turn ability cooldowns on or off
/rezero skill cooldown <player> reset         clear all current cooldowns
/rezero skill manacost <player> <true|false>  turn mana costs on or off

Allies

These need no permission level — they are for players.

/rezero ally request <player>
/rezero ally accept  <player>
/rezero ally decline <player>
/rezero ally remove  <player>
/rezero ally attacks <get | <true|false>>     allow allies to damage you

World and miscellaneous

/rezero chunkmiasma  <get | set <amount>>      miasma in the current chunk
