Configuration

Ten TOML files, every one heavily commented. Nearly every number quoted anywhere on this wiki comes from here and can be changed.

Where the files live

The location differs by loader, and this catches people out constantly. Editing the wrong copy is the single most common reason a config change appears to do nothing.
LoaderScopePath
NeoForge 1.21.1SERVER <world>/serverconfig/hahueuh/server/
Forge 1.20.1COMMON config/hahueuh/

On NeoForge the settings are per world — a new world starts from defaults again, and a file you edited in the global config folder will be ignored. On Forge they are global and shared by every world.

Settings most worth changing

Which protections can be rolled

The four rarity lists in divine_protection_main.toml are the rolling pool. Move an id between lists to change how rare it is, or delete it from every list to remove it from rolls entirely. An id that is listed but not registered is simply ignored.

This is how hahueuh:od_lagna is normally kept out of circulation — it ships in the Divine pool, but a holder can eventually accumulate almost every protection in the game.

How often the world rewinds

In return_by_death.toml, each of the three checkpoint triggers can be disabled independently, and each has its own chance. showCheckpointNotification is off by default — turning it on makes the system far easier to understand while learning it.

Whether Authorities are exclusive

singleAuthorityHolder and singleNamedSpiritHolder in authority_main.toml are both off by default, so any number of players can hold the same Authority. Turn them on for a server where these are meant to be scarce.

How harsh running out of Od is

crippledEnabled in magic_main.toml defaults to true, which makes spending your last Od permanent and irreversible. Setting it false swaps that for a 20 minute magic lockout instead. See Magic.

Turning whole features off

Several systems have a single master switch: Divine Protections, starting magic, ageing, compatibility, Witch's Scent, mob Witch Factors and the checkpoint timer can each be disabled outright without touching anything else.
