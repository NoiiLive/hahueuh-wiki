Configuration

Ten files, all of them heavily commented. Nearly every number quoted anywhere on this wiki comes from here, and all of them can be changed.

Where the files are

The location is different on each loader, and this catches people out constantly. Editing the wrong copy is far and away the most common reason a change seems to do nothing.
LoaderLook in
NeoForge 1.21.1 <your world folder>/serverconfig/hahueuh/server/
Forge 1.20.1 config/hahueuh/

On NeoForge the settings belong to each world, so a new world starts fresh and anything you edited in the main config folder is ignored. On Forge they're global and every world shares them.

The settings people actually change

Which blessings can appear

The four rarity lists in the blessing config are the pool. Move an id from one list to another to change how rare it is, or delete it from all four to take it out of the game entirely. An id that's listed but doesn't exist is just ignored.

This is how hahueuh:od_lagna usually gets removed. It ships in the Divine list, but whoever holds it eventually collects nearly every blessing there is.

How often the world rewinds

Each of the three save triggers can be switched off on its own, and each has its own chance to fire. The notification is off by default, and turning it on makes the whole system much easier to understand while people are still learning it.

Whether Authorities are one to a server

Both the Authority and named spirit exclusivity settings are off by default, so anyone can hold anything. Turn them on for a server where these are supposed to be rare and fought over.

How badly running out of Od hurts

By default emptying your Od cripples you permanently. Switching that off replaces it with a twenty minute magic lockout, which is far more forgiving for a casual server. See Magic.

Turning whole systems off

Several things have a single on or off switch: blessings, starting magic, ageing, how Authorities are earned, Witch's Scent, mobs with Witch Factors, and the save timer. Each can go without disturbing anything else.
