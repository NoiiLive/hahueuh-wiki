Configuration

Where the config files live and what each one controls.

This page is still being written. The structure below is in place; the prose is not finished yet.

Where the files live

The location differs by loader. On Forge the configs are COMMON-scoped and sit in the global config folder. On NeoForge they are SERVER-scoped and live inside the world folder. Editing the wrong copy is the most common reason a config change appears to do nothing.

The config files

FileControls
MainMaster toggles for whole features.
PlayerStats, races, lifespan, aging.
MagicGate rolls, strain thresholds, spell caps, starting magic.
Magic (Yin)Costs and cooldowns for the Yin school.
Divine ProtectionRarity pools, unique list, and per-protection tuning.
SpiritCommune odds, contract limits, spirit stats.
Return by DeathCheckpoint interval and notifications.
DomainGreed's Domain.
SlothUnseen Hands.
GreedRemaining Greed abilities.

Changing what can be rolled

The four rarity lists in the Divine Protection config are the rolling pool. Move an id between lists to change how rare it is, or delete it from every list to remove it from rolls entirely.
