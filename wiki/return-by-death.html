Return by Death

The world checkpoints itself as you play. When you die it rewinds — terrain, mobs, weather, other players — and only you remember it happened.

How it works

While players are online the mod quietly captures the state of the world. When a holder of Return by Death dies, everything is restored to the last checkpoint: block changes, entities, the time of day, the weather, and every other player's position and inventory.

A rollback is not personal. Everyone on the server loses whatever they did since the checkpoint, not just you.

When checkpoints happen

Three separate things can trigger one, and each rolls a chance rather than firing every time — so the exact moment cannot be predicted or farmed.

TriggerChanceNotes
Timer80%Every 60 seconds ± 15.
Earning an advancement80%Real advancements only — recipe unlocks are filtered out.
Sleeping80%
  • No checkpoint is taken while the server is empty. This is deliberate, so a single-player world does not silently drift while you are away.
  • A checkpoint is deferred while any player has a container open, for up to 60 seconds, so it cannot catch a half-finished inventory move.
  • Capture runs on a background thread, so it should not stutter the game.
  • Players are not notified by default. Turn on showCheckpointNotification if you want the message.

You can also force one at any time with /rezero checkpoint.

What survives a rewind

A handful of things are deliberately exempt, because rewinding them would be either meaningless or actively broken:

  • Your memory of the loop, and the Insanity that accumulates with it.
  • Pocket dimensions — Door Crossing rooms and Al Shamak cells.
  • The world's game time. Only the visible time of day is rewound; the underlying monotonic clock is not, because rewinding it breaks command blocks and desyncs every cooldown in the game.
  • Other mods' live databases, which are skipped rather than corrupted.

Witch's Scent

Rewinding leaves a mark. Witch's Scent builds up on a looping player — to a maximum of 5 levels by default — and it is not subtle: it makes you notably worse at communing with spirits, cutting success to 35% of what it would be.

It can be disabled entirely with witchScentEnabled.

Limits

Return by Death makes death a reset, not an immunity. Things that resolve first:

  • Being sealed by Ol Shamak.
  • Being frozen by Lion's Heart.
  • The Phoenix protection, which revives you instead of letting the death happen at all.
Dying on the death screen is a real state. A player who is rolled back before clicking respawn used to be locked out permanently. If you are running an older build and see this, update.

Tuning it

Everything above lives in the Return by Death config: each trigger can be switched off independently, the interval and its randomness are adjustable, and the whole Authority can be disabled. See Configuration.
