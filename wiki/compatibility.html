Mod compatibility

HahUeuh doesn't require any other mod. A few get special handling, and nearly all of that is because Return by Death rewrites the world.

Mods with specific support

ModWhereWhat's handled
CreateBoth loaders Trains and their stored data are dealt with during a rewind, which would otherwise leave contraptions pointing at things that no longer exist.
SableNeoForge only Rewind support. Sable stores its data per chunk, which the restore has to account for.
PlayerReviveBoth loaders HahUeuh notices when you're in PlayerRevive's downed state and can force you up, so it doesn't fight with Phoenix or a rewind.
Better CombatBoth loaders The mod's four weapons come with proper definitions, so Better Combat recognises them instead of guessing from their names.

Those four weapons are the Dragon Sword Reid and the three Bowel Hunter blades: black, white, and the kukri. The kukri is the reason this exists, as it doesn't match the naming rules Better Combat would otherwise use.

None of these are required. Each one is behind a check for whether the mod is present. If it isn't installed, that code never runs.

How rewinds treat other mods

Return by Death restores files on disk, so in principle every mod that saves anything is affected. Three rules keep that from being destructive:

  • Open databases are left alone. A mod holding a file open won't have it swapped out underneath, and one locked file never stops the rest of the restore.
  • Other mods' live player data survives. An older version wiped all of it, which broke mods that keep things there. Only HahUeuh's own saved data gets restored now.
  • The internal clock never goes backwards. Only the visible time of day moves. Winding the real clock back breaks command blocks and every cooldown in the game.

Everything else

Anything not listed here is untested rather than known to be broken. The risk sits almost entirely with Return by Death: a mod that keeps world state somewhere unusual might not come back in step with everything else.

If you hit a conflict, the detail worth reporting is what the other mod saves and where it saves it. That's nearly always where the trouble is.
