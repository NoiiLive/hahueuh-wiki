Mod compatibility

HahUeuh has no hard dependencies. A handful of mods get explicit handling, almost all of it because Return by Death rewrites the world on disk.

Explicitly handled

ModLoadersWhat is handled
CreateBoth Trains and their cached carriage data are handled during rollback, which would otherwise leave contraptions referring to state that no longer exists.
SableNeoForge only Rollback compatibility. Sable keys its held data by physical chunk, which a restore has to account for.
PlayerReviveBoth Detected reflectively at runtime. HahUeuh checks whether a player is in PlayerRevive's bleeding state and can force a revive, so its downed state does not fight with Phoenix or a rollback.
Better CombatBoth The mod's four weapons ship explicit weapon_attributes datapack files, so Better Combat recognises them properly instead of guessing from the item name.

The four weapons with Better Combat definitions are the Dragon Sword Reid and the three Bowel Hunter blades — black blade, white blade and kukri. The kukri in particular does not match Better Combat's name-based rules, which is why the explicit file exists.

None of these mods are required. Each integration is behind a mod-loaded check. If the mod is absent, the code never runs.

How rollback treats other mods

Return by Death restores files on disk, which means every mod that persists data is potentially in scope. Three rules keep this from being destructive:

  • Live databases are skipped. A mod holding an open SQLite file is left alone rather than having its file replaced underneath it, and one locked file never aborts the rest of the restore.
  • Runtime data attachments are preserved. A rollback used to null every player attachment, which broke other mods that keep non-serialised state there. Only HahUeuh's own serialised data is now restored.
  • Game time is never rewound. Only the visible time of day moves. Rewinding the monotonic clock breaks command blocks and desyncs every cooldown in the game, HahUeuh's own included.

Everything else

Mods not listed here are untested rather than known-broken. The risk is concentrated entirely in Return by Death: a mod that stores world state somewhere unusual may not be restored consistently with the rest of the world.

If you hit a conflict, the useful detail to report is what the mod persists and where — that is almost always where the problem is.
